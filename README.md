# Gestão de Lixo em Condomínios

## Sobre o projeto

O **Gestão de Lixo em Condomínios** é um sistema desenvolvido com o objetivo de auxiliar condomínios residenciais na organização e no gerenciamento do descarte de resíduos.

A aplicação busca facilitar o controle da coleta seletiva, incentivar boas práticas ambientais e melhorar a comunicação entre moradores e administração do condomínio sobre o descarte correto do lixo.

Este projeto foi desenvolvido como atividade acadêmica, aplicando conceitos de desenvolvimento de software, organização de dados e boas práticas de programação.

---

## Objetivos

- Organizar o gerenciamento dos resíduos produzidos pelo condomínio;
- Incentivar a separação correta entre lixo reciclável e orgânico;
- Facilitar o acompanhamento das coletas;
- Melhorar a comunicação entre moradores e administração;
- Promover práticas sustentáveis dentro do condomínio.

---

## Funcionalidades

- Cadastro de moradores;
- Cadastro de resíduos;
- Registro do descarte de lixo;
- Controle de coletas realizadas;
- Consulta de informações cadastradas;
- Organização dos dados de forma simples e intuitiva.
